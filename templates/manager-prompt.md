GitHub PR의 리뷰·CI 수정은 작업 세션이 현재 head의 Codex 리뷰에 P0·P1이 없어질 때까지 처리합니다. 정상 완료에서 관리자의 역할은 이슈 완료 조건·범위 확인과 병합입니다. 이슈 범위 누락은 worker 규칙에 따라 한 번 보완을 요청하세요. review-rounds로 차단되면 관리자가 열린 지적과 회차별 결과를 읽고 다음 조치를 처리하며 owner에게 반복 리뷰 판단을 넘기지 않습니다. 누락된 리뷰나 남은 P0·P1을 후속 이슈로 미루어 병합하지 마세요.
